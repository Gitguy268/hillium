Hillium

A privacy layer for the Helium browser: an offline new tab, local search, a Tor switch with a kill switch, and a URL cleaner.

Companion kit for stock Helium on macOS. It is not a separate browser download yet.

What you get

Hillium

Offline new tab

Clock, search and quick links. It makes no network requests at all.

Hillium

Local SearXNG

Runs natively on your Mac without Docker, with a public instance as fallback.

Hillium

Tor and proxy switch

Route everything through your own Tor or any proxy with one click.

Hillium

Kill switch

If Tor drops, pages stop loading. Nothing falls back to a direct connection.

Hillium

WebRTC leak block

Stops WebRTC from revealing your local or real IP.

Hillium

URL cleaner

Strips utm_*, fbclid, gclid and similar, offline.

Helium

uBlock Origin built in

Blocks ads, trackers and cookie banners out of the box.

Helium

Fingerprint noise

Adds noise to canvas, audio and CPU core counts.

Helium

DNS over HTTPS

Presets for Quad9, Cloudflare and NextDNS, plus any custom address.

Install

  1. Install Helium and Homebrew.
  2. Clone the repository and double-click searxng/install.command.
  3. In Helium, open chrome://extensions, turn on Developer mode and load the extension folder.
  4. Add http://127.0.0.1:8888/search?q=%s as a search engine and make it the default.

Tor through Hillium hides your IP, but not your browser fingerprint. If you need anonymity, use Tor Browser.
